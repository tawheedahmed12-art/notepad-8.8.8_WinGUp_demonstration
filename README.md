# notepad-8.8.8_WinGUp_demonstration
Demonstration of how WinGUp had been exploited after the compromisation of the update server.

# WinGUp

WinGUp (Windows General Updater) was created for the Notepad++ as their updater, although other Windows applications can use it. A vulnerability was found February of 2026 that had been persistent for 6 months. 

| CVE | Date | Payload | Details |
|------|------|--------|--------|
| CVE-2025-15556| February 3rd 2026 | Chrysalis Backdoor | Between June and December 2025, a supply chain compromise on the official Notepad++ hosting infrastructure delivered two primary types of malicious payloads via hijacked software updates |

This demonstration was made in a local environment of how the attack would have looked to the victim the attacker and the server.
